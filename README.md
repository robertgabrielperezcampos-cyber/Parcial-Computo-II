## Descripcion
Aplicacion grafica de consultoria de inventario para cinco sucursales: San Salvador, Santa Ana, San Miguel, La Libertad y Sonsonate. Usa pandas para inspeccionar y agrupar los datos, PyQt5 para la interfaz y Matplotlib para los graficos integrados.

## Instalacion
```bash
python -m pip install -r requirements.txt
```

## Ejecucion
```bash
python inventario_app.py
```

El archivo `datos.csv` debe permanecer en la misma carpeta que `inventario_app.py`.

## Funciones
- Filtrar registros por sucursal.
- Mostrar `head()`, tipos de datos, `describe()` y dimensiones.
- Visualizar stock, valor del inventario, ventas por categoria y productos con menor stock.
